ESPSomfy RTS Installer

Version @VERSION@ for ESP32, ESP32-S2, ESP32-S3 and ESP32-C3. The installer picks the right image for the connected chip.

Controller already running ESPSomfy RTS?

You don't need this page. Update through the controller's web UI under System → Firmware, which keeps your configuration. See Installing and flashing.

New installation

Connect the board over USB and press the button. Your browser asks for the serial port.

This writes the complete image and erases everything on the board: Wi-Fi, settings, shades and pairings.
This browser can't access serial ports. Use Chrome or Edge on a desktop computer. Serial access needs HTTPS.

After installing, join the controller's own Wi-Fi access point to set it up.

Repair a board that no longer boots

For a board that shows flash read err, 1000 or invalid header after a flash went wrong, for example after SomfyController.ino.*.bin was written to address 0x0. This writes the bootloader, the partition table and the firmware, and leaves the file system with your shades, rooms and groups alone.

Wi-Fi and settings may have to be entered again. Afterwards, upload SomfyController.littlefs.bin under System → Firmware → Update Application to update the web UI.
This browser can't access serial ports. Use Chrome or Edge on a desktop computer. Serial access needs HTTPS.

If the installer asks whether to erase the device, say no, or the shades are lost.
